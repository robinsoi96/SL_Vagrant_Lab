# Getting Started

## Prerequisites

Please follow all prerequisites mentioned in [Prerequisites folder](../../Prerequisites/) before proceeding.

**NOTE:**

- To understand the actual architecture or design of this project, please navigate to [Architecture folder](../../Architecture/)
- If you wish to modify the project configuration, refer to [Setup_Changes folder](../Setup_Changes/) for available configuration change options

## How to start this project?

After completing the prerequisites, a `venv.txt` file should be available in the [main folder](../../../).

**Steps to kickstart this project:**

1) Copy the full Python virtual environment executable path from `venv.txt`

2) Run the following command to kickstart this project:

    ```shell
    <python_executable_path> main.py

    # <python_executable_path> is the full path copied from Step 1
    ```
